# e-Nigam 🏛️📱

e-Nigam is a mobile civic engagement and smart civic reporting platform designed to bridge the gap between citizens and local governance. The platform empowers users to report public infrastructure issues (like potholes, broken streetlights, or waste management problems) directly to municipal authorities, tracking them from filing to resolution.

## 🚀 Features

* **Smart Civic Reporting:** Seamlessly file complaints with geo-tagging, category selection, and media attachments.
* **AI-Driven Priority Listing:** Smart backend algorithms analyze incoming reports based on severity, location, and density to help authorities prioritize critical issues.
* **Real-time Workflow Tracking:** Citizens can track the exact status of their complaints (Pending, In Progress, Resolved) transparently.
* **Community Upvoting:** Neighbors can upvote existing local issues to boost their visibility and priority instead of filing duplicates.
* **Dashboard for Authorities:** A dedicated view for municipal workers to manage, assign, and update civic tasks efficiently.

## 🛠️ Tech Stack

* **Mobile Framework:** Flutter / React Native (Cross-platform iOS & Android compatibility)
* **Backend & Database:** Supabase (Real-time updates, secure authentication, and relational data handling)
* **Cloud Infrastructure:** Google Cloud Platform (GCP) for hosting backend microservices and handling heavy media processing.
* **AI Pipeline:** Automated triage and priority sorting logic built into the system workflow.

## ⚙️ System Architecture & Workflow

1. **Citizen Reports:** User captures a picture, tags the location via GPS, and submits the issue.
2. **AI Triage:** The platform categorizes the issue and assigns an initial priority score.
3. **Authority Assignment:** Local municipal bodies view the prioritized dashboard and deploy field operations.
4. **Resolution:** Photos of the fixed infrastructure are uploaded, and the citizen receives a real-time status notification.
